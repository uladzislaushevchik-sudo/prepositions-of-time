# Предлоги времени · Interactive Practice

Интерактивные упражнения по предлогам времени (at / in / on + intermediate & advanced).

Основано на презентации «Предлоги времени».

## Как открыть с телефона

1. Скачай файл **Prepositions_of_Time_Interactive.html** из папки проекта (artifacts) или из Google Drive проекта.
2. Открой его в браузере телефона (Chrome / Safari).

Или после включения GitHub Pages:
https://uladzislaushevchik-sudo.github.io/prepositions-of-time/

## Что внутри

- Краткие правила (Basic / Intermediate / Advanced)
- Выбор правильного предлога (с комментариями к каждому ответу)
- Заполнение пропусков
- Исправление ошибок
- Matching (соедини)
- Смешанная практика
- Автоматический подсчёт баллов + подробные объяснения
- Тёмная тема, крупные кнопки, отлично работает на телефоне
